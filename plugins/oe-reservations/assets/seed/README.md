# Dish photos for `wp oe seed`

Put one photo per dish here, named after the dish slug, as `.webp`.
`wp oe seed` uses it as the dish's featured image; dishes without a photo
get a generated illustration (see `--images`).

- Plate seen from above, ideally cut out (transparent background): it is shown in a circle.
- Square, 800 × 800 px, **≤ 60 KB** each, so the seed stays fast in WordPress Playground.

## Expected file names

**Starters:** `charred-flatbread-whipped-feta`, `heirloom-tomato-salad`, `sea-bream-crudo`, `grilled-octopus`,
`burrata-roasted-grapes`, `smoky-aubergine-dip`, `panisse-fries`, `fish-soup-rouille-croutons`

**Mains:** `whole-grilled-sea-bass`, `bouillabaisse-for-two`, `lamb-shoulder-12-hours`, `ember-roasted-chicken`,
`dry-aged-rib-eye`, `squid-ink-linguine`, `wild-mushroom-risotto`, `charred-cauliflower-steak`, `pissaladiere`,
`grilled-prawns-saffron-rice`

**Desserts:** `olive-oil-cake`, `dark-chocolate-tart`, `fig-honey-pavlova`, `lemon-sorbet-limoncello`,
`navettes-coffee`, `cheese-from-provence`

**Wines** (a glass or bottle): `bandol-rose-domaine-des-restanques`, `cassis-blanc-clos-des-falaises`,
`palette-rouge-chateau-belcodene`, `cotes-de-provence-orange`, `cremant-de-die`, `muscat-de-beaumes-de-venise`
